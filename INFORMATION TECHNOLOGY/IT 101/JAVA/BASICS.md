Java Programming :
**Java** is a programming language and computing platform first released by Sun Microsystems in 1995. It provides a reliable foundation upon which a large portion of today's digital services, web applications, and desktop software are built and run.

### **Key Components of Java**

- **Java Runtime Environment (JRE)**: The runtime software required to run Java applications. It includes core platform classes, supporting libraries, and the execution engine.

- **Java Virtual Machine (JVM)**: A core component built directly into the JRE that actually executes Java applications on your computer.

- **Java Development Kit (JDK)**: The software package that contains the development tools necessary for programmers to write, compile, and build Java programs.

Java is free to download for personal use and software development, and receives regular updates to maintain application security, stability, and performance.
